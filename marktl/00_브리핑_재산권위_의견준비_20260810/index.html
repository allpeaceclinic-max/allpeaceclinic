SECTION 01

무엇이 바뀌었나 (사실관계 — 조문 실측 확인)

copy

2026-02-27 시행령 2건이 유예기간 없이 개정·공포·즉시 시행되었다.

법령종전개정
상증세법 시행령 제12조 1호 (공익법인 범위)"종교의 보급 기타 교화에 현저히 기여하는 사업" — 국내외 경계 없음"거주자 또는 비영리내국법인이 종교의 보급, 그 밖에 교화에 현저히 기여할 목적으로 운영하는 사업" — 외국법인·비거주자 제외
법인세법 시행령 제39조 1항 1호 마목 (기부금단체 범위)종교 목적 비영리법인 "(그 소속단체를 포함한다)" — 외국 소재 소속단체 포함 여지"및 국내에 있는 그 소속단체" — 국내 소재로 한정

✅ 제12조 1호 개정 문언은 2026-08-10 국가법령정보에서 직접 확인함(공포·시행 2026-02-27 현행본). 종전/개정 대비는 김영근 회계사 자료 기준.

경위: 한 이단 단체(⭐사실확인 2026-08-10: 데일리굿뉴스 7/24가 신천지로 실명 보도 — 본부 과천 = 수원지법 관할로 판결번호와 일치. 블로그의 "통일교" 표기는 근거 보도 0건, 오보 판단)가 2012~2017 LA·남아공 지부에 85억 송금 → 서울지방국세청 증여세 52억 부과 → 소송 → 대법원 2025.5.15. 선고 2025두30806 과세 취소 확정(법령에 국내외 경계가 없어 해외 송금도 비과세 대상) → 국세청 건의·기재부 채택으로 시행령 개정. 대법원이 판결문에서 해외 선교사업의 공익적 성격을 인정했음에도, "악용 방지 위해 국내 거주자로 한정하라"는 보충 의견만 법 개정 근거로 채택됐다는 것이 김영근 위원장(한교총 세정대책위원장)의 지적.

효과 (2중 차단):

  • 나가는 길: 국내 교회·단체가 해외 지교회·현지 선교법인·비거주자에게 선교비 송금 → 증여세 과세가액 불산입(상증세법 §48) 적용 불가 → 증여세 부담 (교단 연간 해외 선교 지출 7,000~8,000억 규모, 최대 70% 과세 가능 주장)
  • 들어오는 길: 해외 단체로 나가는 헌금에 대한 성도의 기부금 세액공제 배제 가능성. 특히 지정 헌금이 해외로 나간 경우 세무조사 시 헌금 낸 성도 개인이 증여세 납부 의무자가 될 수 있음
★ KEY INSIGHT

인터서브코리아(ISK) 노출 지점 — 4가지

copy

공청회 Q&A에서 나온 결론 중 ISK에 직결되는 것:

"국제 선교단체 한국지부가 해외 본부 등에 내는 분담금 역시 세법상 '외국 법인'에 대한 지출로 분류돼 모두 과세 대상" (국민일보 8/7)

#노출 지점내용연결 쟁점
①IO 분담금CofF D.5상 국가 사무국의 IC 승인 분담금 → IO(영국 등록 자선단체 = 외국법인) 송금이 과세 대상 분류 가능. CofF 개정안이 재정 조항을 전혀 다루지 않는 상황(I-018)에서 한국 세법 리스크까지 겹침 — LC2026 의견 상신에 반영할 실증 근거I-018
②파트너 송금파트너는 해외 장기 체류자 → 세법상 비거주자 판정 시 종교인 소득신고 혜택 불가, 사례비·활동비 전액 과세 가능(김영근 경고). ISK→파트너 생활비·사역비 송금 경로의 세무 분류 확인 필요51_ 허입·파송
③현지 프로젝트·부동산해외 부동산 취득·구제활동·사회사업 지출은 "과세 관계 명확해질 때까지 보류" 권고. 국내 단체 경유 우회지출(월드비전 등)도 증여세 과세 대상(김영근 자료 명시)EG-001 · JP-001 컨설팅
④후원 구조ISK는 비영리 내국법인이므로 후원자→ISK 기부 자체는 유지될 것으로 보이나, ISK 지출의 대부분이 해외 송금이라는 구조상 목적사업비 인정 여부가 관건. 사무국 세무 자문 확인 필요 (추정 — 미검증)—

★ KEY INSIGHT

강대흥 사무총장 「선교·구조적 제안」 (슬라이드 36쪽 전량 판독, 2026-08-10)

copy
  • 통계로 세운 전제 — 선교 지형 역전: 전세계 장기 선교사 1970년 258,000명(Global North 88%) → 2021년 430,000명(GN 53%/GS 47%) → 2026년 455,000명(Global North 178,000명 39% / Global South 277,000명 61%). 비서구 출신이 다수가 된 시대에 "돈을 보내는 선교" 모델 자체를 재검토하자는 논리 구조
  • 동반자 선교: 목사 선교사는 현지 교단과 동역(현지 교단 이름으로 사역), 평신도 선교사는 현지 교회 출석·Hospitality 중심 — "재정이 요구되는 사역은 하지 않도록", 가능하면 현지 직장으로 재정 창출
  • 경제적 선교(Mission in Economic): 중복 투자·경쟁적 사역 확장 지양, 건축보다 제자 양육 먼저, "은행 통해 송금 받지 않는 구조는 지양" — 수원국 측 규제 실례: 네팔(교회 헌금 해외의존 과거 40% → 현재 15% 미만), 캄보디아(정책 고려 중), 인도(건축 재정 출처 확인하고 증여세 부과), 파키스탄(원천징수세). "Project는 가급적 하지 않는다"
  • 교단 공동 기반: 2026-01-20~21 「현지중심 동반자 선교 활성을 위한 한국 교단 선교 MOU」 — 8개 교단 서명(한국교단선교실무대표협의회 주최, KWMA 주관). 세법 사태 이전부터 이미 동반자 선교로의 전환 합의가 있었음을 보여주는 근거
  • 📌 재산권위 관점 포인트: 보내는 쪽(한국 세법)과 받는 쪽(인도·네팔 등 현지 규제)이 양쪽에서 동시에 조여오는 구조 — "건축·프로젝트 중심에서 벗어나 거버넌스·이양 중심으로"라는 위원회 가이드라인 방향과 정확히 수렴. 인도의 "건축 재정 출처 확인 후 증여세" 사례는 EG-001·JP-001 컨설팅 권고안에 인용 가능

한교총 권고 실무 지침 (김영근):

  1. 선교사 정기 사례비 → 종교인 소득신고 + 연말정산 전환
  2. 필요경비 → 정관에 '선교활동비' 규정 삽입 후 비과세 처리 (법적 타당성 검토 중, 한교총 통해 발표 예정 — 가능성 높다고 표기)
  3. 해외 부동산·구제·사회사업·기타 활동비 지출 → 보류 + 건별 정당성 확인 후 결정
  4. 비거주자 판정 리스크 → 개별 사례 법률 검토 필수
SECTION 05

재산권위원회 관점 — 의견 초안 (대표 회신용 후보)

copy

이 사안은 위원회가 만들어 온 가이드라인의 방향(투명성·구조성·기록과 소통·연 2회 보고)이 그대로 세법 대응 수단이 되는 국면. "감시가 아닌 보호"라는 위원회 철학이 실증되는 사례로 프레임 가능.

(a) 단기 — 사무국 확인 (8월)

  • 임민정 매니저(재정)·세무 자문을 통해 ISK 재정 흐름 3종의 세무 분류 확인: ①IO 분담금 ②파트너 생활비·사역비 송금(비거주자 판정 포함) ③현지 프로젝트 지출
  • 신규 해외 부동산·프로젝트성 지출은 한교총 지침대로 보류 원칙 공유 (진행 중인 컨설팅 케이스 EG-001·JP-001의 권고안에도 반영)

(b) 정관 — I-016 연계

  • 차기 정관 개정(공백 5종 보완) 시 '선교활동비' 규정 삽입을 안건에 추가 — 한교총 법적 타당성 검토 발표를 기다렸다가 문안 반영

(c) 가이드라인 — 스타터 패키지 반영 (I-012·I-002)

  • B1 자가진단·B2 행정문서 체크리스트에 세법 사후관리 증빙 항목(파송계약·사업계획·예산결산·현지 법정 영수증·용도 증명) 통합 — 한교총이 제도화하려는 요건과 위원회 체크리스트를 처음부터 정렬
  • 11/26 랩업 모임 안건으로 상정

(d) 연대·모니터링

  • KWMA 회원단체로서 한교총 TF 경과(11월 말 시한)를 추적하고, 필요 시 ISK 사례(국제단체 한국지부 분담금 문제)를 개선안 논의에 제공 — 이 유형은 개교회 사례와 달라 별도 쟁점화 가치 있음

(e) LC2026 연결 (I-018)

  • CofF 개정 의견 상신에 "각국 세법 환경이 국제 재정 구조에 미치는 영향(한국 2026-02 시행령 개정 실례)"을 포함 — 개정안이 재정을 다루지 않는 공백을 지적하는 실증 근거로 사용
